# Promo Publisher — акции LariBrand

Скилл заменяет текущую акцию на новую. Вся акция управляется одним конфигом
`src/lib/promo.ts`; страница `/promo`, попап на входе, ссылка «АКЦИЯ» в шапке и
запись в sitemap подхватывают его автоматически. Работа сводится к: вычитать
данные с макетов → подготовить медиа → обновить конфиг и литералы → тесты и
проверки → коммит.

## Вход от пользователя

Обычно это файлы из Telegram (`~/Downloads/Telegram Desktop/IMG_*.JPG|MOV`):
- афиша-обложка кампании (постер со всеми предложениями и датами);
- постеры отдельных предложений (фото-карточки с составом, временем, ценами);
- видео-карточки предложений (MOV, обычно 4:5 или 9:16).

Даты, цены, состав и названия ВСЕГДА написаны на макетах — вычитывай их с
изображений, не выдумывай. Если чего-то на макетах нет (например, старой цены) —
спроси пользователя.

## Шаг 1. Вычитать данные с макетов

1. Прочитай каждое изображение через analyze_image (Read на локальном jpg вернёт
   только CDN-ссылку — анализируй именно её).
2. Зачёркнутые старые цены vision-модели читают плохо. Обязательно подтверди
   каждую цифру кропом зоны цены (`ffmpeg -i img.jpg -vf "crop=W:H:X:Y" crop.jpg`,
   затем повторный analyze_image). Сверяй по главной афише — она мастер-источник;
   расхождения между афишей и карточкой (бывали) решай в пользу афиши и сообщай
   пользователю.
3. Видео: сними раскадровку контактным листом и прочитай плашки:
   `ffmpeg -i video.MOV -vf "fps=1/2,scale=360:-2" f_%02d.jpg`, затем
   `ffmpeg -i f_%02d.jpg -vf "scale=270:-1,tile=4x2" sheet.jpg`.

## Шаг 2. Медиа-конвейер

Подробные команды — в `references/media-pipeline.md`. Суть:
- видео MOV → `public/promo/IMG_XXXX.mp4` (H.264 CRF 27, +faststart, ~2 МБ);
- постер видео → `IMG_XXXX-poster.jpg` (кадр на 1-й секунде, 720px, q 4);
- фото-карточки → `IMG_XXXX-poster.jpg` (810px, качество 82);
- афиша → копия оригинала в `public/promo/` (она и обложка, и OG-картинка);
- ВСЕ файлы прошлой акции из `public/promo/` удалить (пользователь просит
  именно замену; старые файлы не копятся).

## Шаг 3. Конфиг `src/lib/promo.ts`

Обновить ВСЕ поля:

| Поле | Что это |
|---|---|
| `PROMO_START` / `PROMO_END` | ISO-8601 со сдвигом Саратова `+04:00`. END = полночь ПОСЛЕ последнего дня (акция «9–15 ноября» → END `...-11-16T00:00:00+04:00`) |
| `PROMO_PERIOD_LABEL` | «с 9 по 15 ноября включительно» — подставляется в тексты страницы |
| `PROMO_DATES_LABEL` | «9–15 ноября» — бейджи и metadata |
| `PROMO_DEADLINE_LABEL` | «до 15 ноября включительно» — попап и таймер |
| `PROMO_STORAGE_KEY` | ОБЯЗАТЕЛЬНО сменить (`laribrand-promo-popup-<период>-closed`), иначе попап не покажется повторно сессиям, закрывшим прошлую акцию |
| `PROMO_HEADLINE` | H1 страницы и заголовок попапа |
| `PROMO_BENEFIT_LABEL` | краткая суть для текстов |
| `PROMO_MEDIA.campaignCover` | путь афиши-обложки |
| `PROMO_OFFERS[]` | по одному на предложение: `id`, `title`, `subtitle` (Комбо N в 1 · состав), `description`, `poster`, `videos` (для фото-предложения — пустой массив), `duration`, `oldPrice`, `price`, `benefitLabel` («выгода N ₽» = разница цен), `benefits` |

Порядок предложений = порядок на афише. `PROMO_OFFERS_COUNT` и
`PROMO_MIN_PRICE_LABEL` считаются сами.

## Шаг 4. Литералы вне конфига

Большинство дат подтянется из конфига, но в этих файлах остаются кампании-
специфичные фразы — проверь и обнови по grep:
- `src/app/promo/page.tsx` — metadata description, абзац под H1 («Четыре
  комбо-ухода: …»), заголовок секции предложений («Четыре повода сиять»),
  подпись под ним, тексты InactivePromo, размеры OG-картинки (width/height под
  фактическую афишу);
- `src/components/PromoPopup.tsx` — описание акции под заголовком;
- `src/lib/promo.test.ts` — describe и граничные даты;
- `src/components/PromoPopup.test.tsx` — `setSystemTime` внутри периода и дата
  неактивности (END).

Grep-хелпер: `grep -rn "ноябр\|декабр\|повод\|комбо\|предложени" src/app/promo/page.tsx src/components/PromoPopup.tsx`

## Шаг 5. Пропорции медиа

Верстка держит рамки под соотношение файлов. Сейчас везде `aspect-[4/5]`
(макеты 1080×1350): hero и InactivePromo в page.tsx, левая колонка попапа,
`PromoOfferMedia`. Если новые файлы 9:16 (1080×1920) — замени `aspect-[4/5]` на
`aspect-[9/16]` в этих четырёх местах, иначе афиша/карточки будут обрезаны.
Мобильная полоса-баннер попапа — горизонтальный кроп афиши, позицию смотрите по
`object-[center_22%]` (подбери, чтобы в полосу попал заголовок афиши с датами).

## Шаг 6. Проверки

```bash
npx eslint . --max-warnings=0 && npx jest --silent && npm run build
```

Юридический минимум уже вшит в финальную секцию страницы (срок действия +
«итоговую стоимость уточним на консультации») — не удаляй его. Новые типы
акций без указания срока и условий не публикуй (см. LEGAL_AUDIT_2026-10-15.md).

## Шаг 7. Визуальная проверка

Если акция ещё не началась, страница покажет заглушку «Скоро». Чтобы увидеть
активное состояние: сохрани копию `promo.ts`, временно поставь `PROMO_START`
прошлой датой, прогони проверки, верни файл. Скриншоты — playwright-core из
соседнего проекта с системным Chrome (chromium в кэше playwright тоже есть):

```js
const pw = require('/Users/dmitriy/Projects/Mana/node_modules/playwright-core')
const browser = await pw.chromium.launch({
  executablePath: '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome',
  headless: true,
})
```

Сервер: `npx next dev -p 3999`. Снимай `/promo` (1440 и 390px, fullPage) и `/`
(попап открывается через ~900 мс). ВАЖНО: перед fullPage-скриншотом прокрути
страницу до конца и обратно — next/image ленивый, иначе карточки нижеfold выйдут «пустыми» на скриншоте. Проверяй: афиша без обрезки текста, медиа во всех
карточках, счётчик 01/NN, цены, попап поверх cookie-баннера (z-index попапа
z-[1100] против z-[1000] у баннера).

## Шаг 8. Коммит

Коммить с осмысленным сообщением («Акция 9–15 ноября: комбо-уходы»). Пуш
запускает CI/CD деплой на VPS — НЕ пушить без явного подтверждения пользователя.

## Частые грабли

- Забыли сменить `PROMO_STORAGE_KEY` → попап не покажется прежним посетителям.
- `PROMO_END` поставили последним днём акции → последний день акция «выключена»
  утром. END = полночь следующего дня.
- Vision перепутал зачёркнутую цену → всегда кроп-верификация (шаг 1.2).
- Удалили файл, на который ссылается `poster`/`videos` конфига → 404 медиа.
- Файлы из Telegram — «untrusted»: скрипты пиши вне папок загрузки, пути
  передавай аргументами.
